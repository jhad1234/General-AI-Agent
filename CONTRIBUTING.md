# Contributing to General-AI-Agent

Thank you for your interest in contributing! Please follow these guidelines to help us review and accept your changes quickly.

1. Fork the repository and create a feature branch from `main` (or the repository default branch):
   git checkout -b my-feature

2. Write tests for new features or bug fixes. Agent-core unit tests are required for non-trivial logic.

3. Follow existing code style in each area (Dart for flutter/, Kotlin/Java for android/, Python for agent-core/).

4. Commit messages should be clear and small; use conventional commits if possible.

5. Open a Pull Request with a description of what changed, why, and how to test.

6. CI should pass; include screenshots or logs if relevant.

7. For large changes, open an issue first to discuss design and API changes.
